# Portfólio — Matheus Yoshida Dias

Site pessoal de página única (TI & Automação), com modo claro/escuro e paleta pastel.

Feito em HTML, CSS e JavaScript puros — sem dependências nem etapa de build.

## Ver localmente

Abra o `index.html` no navegador.

## Estrutura

```
index.html      conteúdo do site
css/style.css   estilos (tokens de cor em OKLCH)
js/main.js      alternância de tema claro/escuro
assets/         foto, certificados (PDF) e prévias
```
